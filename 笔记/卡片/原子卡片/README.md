# 卡片/原子卡片 · 怎么用

这里是你的**知识卡片**。规矩很简单：**一个想法，一张卡**。

## 怎么建
命令面板（`Cmd+P`）→「模板：插入模板」→ 选**原子卡片模板**。
文件名会自动带时间戳（比如 `202608181530-卡片笔记法`），不用自己编号。

## 怎么写
- **想法**：把这个想法用自己的话说清楚（别复制粘贴，要写理解）
- **标签**：给它打几个主题标签，比如 `#卡片笔记法`
- **来源**：从哪看到的（书/文章/聊天）
- **连接**：和相关的卡片互相 `[[链接]]`——卡片越多，网越大

## 什么时候写
- 日志收件箱里冒出想法的时候
- 学到新东西有感触的时候

## 小提示
- 卡片会自动出现在当前 [[笔记/目标/十二周周期/README|周期页]] 的"本周期产生的卡片"里
- 同一主题攒到 5 张以上，建个 [[笔记/卡片/MOC/README|MOC]] 目录页整理一下
