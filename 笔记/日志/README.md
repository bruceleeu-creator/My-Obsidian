# 日志 · 怎么用

这里是你的**每日日记**，一天一篇，也是整个系统的入口。

## 怎么建
不用自己建。Obsidian 的日记功能（侧边栏日历图标，或命令面板搜"打开今天的日记"）会自动生成今天的日志。

## 里面有什么
- **今日重点**：今天必须完成的 2-3 件事（页面下面会自动显示本周没做完的任务，从这里挑就行）
- **收件箱**：想到什么随手扔进来，别整理，别判断
- **日志记录**：今天干了啥、心情咋样、卡在哪了

## 每天怎么过
1. **早上**：打开今天的日志，勾 2-3 件今日重点
2. **随时**：有想法就扔收件箱
3. **下班前**：把收件箱里的东西分类——
   - 要干活的事 → 写进 [[笔记/任务/周任务/README|周任务]]
   - 学到的知识 → 丢进 [[知识卡片/raw/README|raw 素材箱]]（攒够了喊 Claudian 整理成 wiki）
   - 跟目标有关的 → 记到 [[笔记/目标/十二周周期/README|周期目标]]

## 小提示
页面下的"本周任务总览"是自动的：周任务里勾掉一件事，这里就少一件。日志也会自动汇总到当周的周任务页里。
