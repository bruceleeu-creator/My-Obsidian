# 目标/十二周周期 · 怎么用

这里是你的**大目标**。一年拆成 4 个周期，每个周期 12 周，只盯 3-5 个目标。这是你所有行动的"方向盘"。

## 怎么建（每 12 周一次）
1. 命令面板 →「模板：插入模板」→ 选**十二周周期模板**
2. 文件名叫 `2026-Cycle-3` 这种格式
3. 填上开始和结束日期（见下面周期表），目标写 3-5 个，每个附一句"怎么算做到"

## 怎么用
- **每周**：周末在 [[任务/周任务/README|周任务]] 里给每个目标打 1-5 分，分数记到这里的评分表
- **页面自动显示**：本周期的所有周任务，不用自己整理
- **周期结束**：把最上面的 `status` 改成 `completed`（存档），建下一个周期，顺便更新 `Claudian.md/模板/周任务模板.md` 里的周期链接

## 小提示
评分表 12 行，一行一周。分数忽高忽低很正常，看整体趋势就行。
