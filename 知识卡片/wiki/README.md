# wiki 知识库

这里是**提炼后**的知识：一个主题一篇文档，按分类存放，像你自己的 Wikipedia。

**这里不用你动手写**——raw 里攒了素材，喊 Claudian 帮你分类整理：内容归类、合并重复、补全结构。

格式约定：
- 一篇一个主题，文件名 = 主题名（如 `利润表兼容性修复.md`）
- frontmatter 带 `type: wiki` 和分类标签
- 分类会按你的知识领域划分，目录结构慢慢长出来
