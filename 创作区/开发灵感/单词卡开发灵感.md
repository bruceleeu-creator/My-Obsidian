# 单词卡 · 开发灵感

> 核心思路：基于 Anki 开源生态做自己的单词卡，配合开学后「每天学习 + 记笔记」的节奏。

## 🎯 起点（2026-08-27 记录）
- **Anki 开源**——间隔重复（SRS）算法成熟，牌组 / 同步生态完善，不重复造轮子

## 🧭 方向草案（待 W36 调研定稿）
- **接入方式**：先复用 Anki 的 SRS 与牌组体系，再决定自建客户端还是直接用 Anki Desktop / AnkiDroid + 同步
- **与开学节奏绑定**：每天固定「新学 + 复习」量，复习完成度进当天日志
- **词库来源**：课程 / 笔记里随手收集生词 → 进牌组（收集流程待设计）

## ❓ 待想清楚的问题
1. 自建客户端，还是直接用 Anki 现有端 + 同步服务？
2. 单词数据从哪来：手动录入 / 笔记自动提取 / 现成词表导入？
3. 要不要和日志系统打通（每天复习完成度自动记进日志）？
4. 密钥 / 同步服务凭据从一开始就走安全存储（呼应 🔒 安全整改规范，不留明文）

- **Cycle-4 起**：按方案启动 MVP 开发
