# 硅行业市场分析系统 · 开发灵感

> 目标：一站式硅（工业硅 / 多晶硅）市场数据分析看板

## 1️⃣ 数据获取（API 接入）
- **上海有色金属网**：<https://data.smm.cn/item/硅>
- **钢联 Mysteel**：<https://mds.mysteel.com/>

## 2️⃣ 分析功能（自主研发）

### 数据看板
- **一站式联通**：期货（广期所 SI）+ 多源现货 + 库存 + 产量 + 成本，全部在一个看板
- **可交互分析**：自选时间段、选牌号，自动算基差、供需平衡
- **预警 + 简单策略提示**：库存异常、基差异常、产量突变
- **更干净的可视化**：摆脱传统 Excel 风格研报图表

### 可视化图表规划
- **期现价格对比图**：现货 553# + 期货主力 + 基差
- **基差走势图**
- **全国 / 分产区周度产量柱状图 + 开工率**
- **社会库存 + 厂库 + 仓单堆叠图**
- **成本 - 利润曲线**
