# 防弹笔记法

## 一、核心理念

**日志收件箱 + ACT 三步分流**：所有信息先随手扔进每日日志，再分流向正确的地方。

| 信息类型 | 去向 |
|---------|------|
| **A** 任务相关信息 | → 归入 [[任务/周任务/README\|周任务笔记]] |
| **C** 知识想法和观点 | → 丢进 [[知识卡片/raw/README\|raw 素材箱]]，提炼成 [[知识卡片/wiki/README\|wiki 知识库]] |
| **T** 方向与目标 | → 连接到 [[目标/十二周周期/README\|十二周目标]] |

**日常案例**：
1. **今日重点**：今天必须完成的 2-3 件事（从周任务中拉取）
2. **收件箱**：随手扔进来，不判断，不整理
3. **日志记录**：今天干了啥、有啥感受、卡在哪里
4. 通过 Obsidian 数据库（Dataview）自动显示

## 二、系统需求

**目标**：模板驱动的闭环系统——记录（日志）→ 行动（任务）→ 认知（raw→wiki）→ 方向（目标）自然流转，数据自动聚合，减少手工维护。

2. 周任务勾选 → 日志列表同步消失

4. 全程零手改查询
5. 模板集中管理

## 三、系统设计

### 目录结构
```
（vault 根）
├── Claudian.md/
│   ├── AGENT.md           协作上下文（必读）
│   └── 模板/              3 个模板 + 防弹笔记法.md
├── 知识卡片/               知识管线（raw 素材 → wiki 知识库）
│   ├── raw/               原始素材（乱丢区，不整理）
│   └── wiki/              提炼知识（分类存放）
├── 任务/
│   ├── 日志/               每日日志（收件箱入口）
│   └── 周任务/             周任务笔记
└── 目标/十二周周期/          12 周目标
```

### 数据流
```
每天：日志（今日重点/收件箱/记录）→ 下班前 ACT 分流
每周：周任务笔记（从周期目标拆任务）→ 周末回顾 + 目标评分
每 12 周：建新周期（3-5 目标）→ 旧周期 status: completed
```

| ----------------------------------- | ---- | ----------------- | --------------------------------- |
| [[Claudian.md/模板/日志模板\|日志模板]]       | 每日日志 | `2026-08-18.md`   | [[任务/日志/README\|日志/]]             |
| [[Claudian.md/模板/周任务模板\|周任务模板]]     | 周任务  | `2026-W34.md`     | [[任务/周任务/README\|任务/周任务/]]     |
| [[Claudian.md/模板/十二周周期模板\|十二周周期模板]] | 周期目标 | `2026-Cycle-3.md` | [[目标/十二周周期/README\|目标/十二周周期/]] |

### 命名规则
| 文件 | 格式 | 示例 |
|------|------|------|
| 日志 | `YYYY-MM-DD` | `2026-08-18.md` |
| raw 素材 | `YYYY-MM-DD 随便写` | `2026-08-19 兼容性笔记.md` |
| wiki 知识 | `主题名` | `利润表兼容性修复.md` |
| 周任务 | `YYYY-Www`（ISO 周） | `2026-W34.md` |
| 十二周周期 | `YYYY-Cycle-N` | `2026-Cycle-3.md` |

### 关键属性（Dataview 的基石）
| 属性 | 适用 | 格式 |
|------|------|------|
| `week` | 日志 | `"[[2026-W34]]"`（带引号双链） |
| `cycle` | 周任务 | `"[[2026-Cycle-3]]"`（带引号双链） |
| `type` | 全部 | `log / weekly / cycle / raw / wiki` |
| `status` | 周任务/周期 | `active / completed` |
| `date` / `created` | 日志/raw | `YYYY-MM-DD` |
| `tags` | raw/wiki | 主题标签 |

### 自动聚合（Dataview 查询）
| 位置 | 显示内容 |
|------|---------|
| 日志页 | 当周未完成任务（从周任务拉取） |
| 周任务页 | 本周所有日志汇总 |
| 周期页 | 本周期全部周任务 |
| 仪表盘 | 当前周期 / 本周任务 / 最近素材 |

### 边界情况
| 场景 | 处理 |
|------|------|
| 跨年 | ISO 周编号自动正确 |
| 任务延期 | 手动复制到下周笔记 |
| 周期切换 | 旧周期 `status: completed`，新建周期，更新周任务模板的 `cycle` 链接 |
| 查询报错 | 检查 `week`/`cycle` 是否带引号双链 |
