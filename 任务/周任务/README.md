# 任务/周任务 · 怎么用

这里是你的**周任务清单**，一周一篇。所有"要干活的事"都归这里管。

## 怎么建（每周一次）
1. 命令面板（`Cmd+P`）→「模板：插入模板」→ 选**周任务模板**
2. 文件名叫 `2026-W34` 这种格式（年份-W+周数），本周就是 `2026-W35`（下周）这样往后排

## 里面有什么
- **本周任务**：这周要干的事，打勾表示完成
- **周回顾**（周末填）：这周干得咋样，有啥心得
- **目标评分**（周末填）：给周期目标打 1-5 分
- **本周日志**（自动）：这周每天的日记会自动汇总在这，不用管

## 每周怎么过
1. **周一**：新建本周任务，从 [[目标/十二周周期/README|当前周期目标]] 里拆出 2-3 件要事
2. **每天**：日志页从这周任务里挑今日重点
3. **周末**：回顾 + 给目标打分

## 小提示
- 任务没做完？直接复制到下周的任务里就行
- 别忘了：每 12 周换新周期时，`Claudian.md/模板/周任务模板.md` 里的周期链接要改成新周期（不然新周任务会挂到旧目标上）
