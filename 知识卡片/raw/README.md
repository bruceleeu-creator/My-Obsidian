# raw 素材箱

这里专门丢「学到的东西」——看文章、看视频、干活过程中学到的经验、突然冒出来的新想法，**全部先扔进来**。

**这里不需要整理，越乱越好。** 标题随便起（建议带日期，比如 `08-19 浏览器兼容性笔记`），想到啥写啥，不用管格式，不用管分类。

扔进来之后：
- 攒得差不多了，喊 Claudian：「整理 raw」→ 提炼成 [[wiki/README|wiki]] 里的知识文档
- 提炼过的原始素材可以删掉，或者标 `done`

> 一句话：raw 是垃圾桶，wiki 是书架。先扔，再整理。
