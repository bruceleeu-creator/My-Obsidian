# 开发工作方式

从实战中沉淀的开发经验，保证项目可持续维护、协作顺畅。

## 核心原则
1. **上下文文档先行**：写 AGENT.md 和 README 很重要——让新来的 AI / 人能快速上岗，不用重新解释。
2. **表述必须清晰**：说不清就先查清楚再写（参考 mattpocock 的清晰表达），模糊表述会传染整个项目。
3. **先页面后逻辑**：vibe 先设计页面 HTML，再填前后端开发，专注功能打通。
4. **文档写明推送方式**：在文档里写清推送地址和命令，防止新人被代理 / 权限问题拦截。

## 适用场景
- 新项目初始化
- 与 AI 协作开发
- 团队知识交接
