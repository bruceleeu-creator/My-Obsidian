# 防弹笔记法

## 一、核心理念

**日志收件箱 + ACT 三步分流**：所有信息先随手扔进每日日志，再分流向正确的地方。

| 信息类型 | 去向 |
|---------|------|
| **A** 任务相关信息 | → 归入 [[笔记/任务/周任务/README\|周任务笔记]] |
| **C** 知识想法和观点 | → 提炼成 [[笔记/卡片/原子卡片/README\|原子卡片]] |
| **T** 方向与目标 | → 连接到 [[笔记/目标/十二周周期/README\|十二周目标]] |

**日常案例**：
1. **今日重点**：今天必须完成的 2-3 件事（从周任务中拉取）
2. **收件箱**：随手扔进来，不判断，不整理
3. **日志记录**：今天干了啥、有啥感受、卡在哪里
4. 通过 Obsidian 数据库（Dataview）自动显示

## 二、系统需求

**目标**：模板驱动的闭环系统——记录（日志）→ 行动（任务）→ 认知（卡片）→ 方向（目标）自然流转，数据自动聚合，减少手工维护。

## 三、系统设计

### 目录结构
```
（vault 根）
├── Claudian.md/
│   ├── 防弹笔记法.md       系统文档
│   └── 模板/              5 个模板集中存放
└── 笔记/                   所有内容笔记
    ├── 00-仪表盘.md        总览页
    ├── 日志/               每日日志（收件箱入口）
    ├── 任务/周任务/         周任务笔记
    ├── 卡片/
    │   ├── 原子卡片/        知识卡片
    │   └── MOC/            主题地图
    └── 目标/十二周周期/      12 周目标
```

### 数据流
```
每天：日志（今日重点/收件箱/记录）→ 下班前 ACT 分流
每周：周任务笔记（从周期目标拆任务）→ 周末回顾 + 目标评分
每 12 周：建新周期（3-5 目标）→ 旧周期 status: completed
```

### 命名规则
| 文件 | 格式 | 示例 |
|------|------|------|
| 日志 | `YYYY-MM-DD` | `2026-08-18.md` |
| 周任务 | `YYYY-Www`（ISO 周） | `2026-W34.md` |
| 原子卡片 | `YYYYMMDDHHMM-短标题` | `202608181530-卡片笔记法.md` |
| 十二周周期 | `YYYY-Cycle-N` | `2026-Cycle-3.md` |
| MOC | `主题名.md` | `卡片笔记法.md` |

### 关键属性（Dataview 的基石）
| 属性 | 适用 | 格式 |
|------|------|------|
| `week` | 日志 | `"[[2026-W34]]"`（带引号双链） |
| `cycle` | 周任务 | `"[[2026-Cycle-3]]"`（带引号双链） |
| `type` | 全部 | `log / weekly / card / cycle / moc` |
| `status` | 周任务/周期 | `active / completed` |
| `date` / `created` | 日志/卡片 | `YYYY-MM-DD` |
| `id` | 卡片 | `YYYYMMDDHHmm` |
| `tags` / `target-tag` | 卡片/MOC | 主题标签 |

### 自动聚合（Dataview 查询）
| 位置 | 显示内容 |
|------|---------|
| 日志页 | 当周未完成任务（从周任务拉取） |
| 周任务页 | 本周所有日志汇总 |
| 周期页 | 本周期全部周任务 + 周期内创建的卡片 |
| MOC 页 | 该主题全部卡片 |
| 仪表盘 | 当前周期 / 本周任务 / 最近卡片 |

### 边界情况
| 场景 | 处理 |
|------|------|
| 跨年 | ISO 周编号自动正确 |
| 任务延期 | 手动复制到下周笔记 |
| 周期切换 | 旧周期 `status: completed`，新建周期，更新周任务模板的 `cycle` 链接 |
| 查询报错 | 检查 `week`/`cycle` 是否带引号双链 |
