# 开源效率工具集

收藏的高价值开源项目，按用途分类，每个工具一句话说清"能干什么"。

## 前端 / UI
- **hallmark** — 去 AI 味的前端生成
  <https://github.com/nutlope/hallmark>
  AI 生成网页后普遍带"模板味"，hallmark 专门做去 AI 味处理，让页面看起来更像真人手写。适合生成完页面后过一遍，消除机械感。
- **taste-skill** — 前端 UI 设计审美外挂
  <https://github.com/Leonxlnx/taste-skill>
  给 AI 注入 UI 设计审美，提升生成界面的视觉质量，相当于设计品味外挂。和 hallmark 互补：一个管自然感，一个管美观度。

## AI 工作流
- **scientific-agent-skills** — 把科研流程交给 agent 托管
  <https://github.com/k-dense-ai/scientific-agent-skills>
  把科研工作流（文献调研、实验设计、数据分析）封装成可复用的 agent 技能。适合长流程、多步骤的科研任务，让 AI 托管整条链路。
- **ponytail** — 省 90% token + 23% 速度
  <https://github.com/dietrichgebert/ponytail>
  通过 prompt 压缩大幅减少 token 消耗（号称省 90%），同时提升处理速度 23%。token 敏感或跑批量任务时的省钱利器。

## AI 技能 / 人格蒸馏
- **awesome-ai-persona-skills** — AI 人格技能蒸馏大全
  <https://github.com/momozi1996/awesome-ai-persona-skills>
  精选"把 AI 人格/技能蒸馏成技能包"的仓库合集，一站式找现成人格技能。想复刻某个领域专家风格时，先来这里翻。
- **awesome-human-distillation** — 人类专家蒸馏成 AI 技能的大全
  <https://github.com/mliu98/awesome-human-distillation>
  围绕"人类专家 → AI 技能"蒸馏主题的精选资源清单。和上一个互补：一个偏人格、一个偏专家知识。
- **council-of-high-intelligence** — 人物蒸馏（多视角决策委员会）
  <https://github.com/0xnyk/council-of-high-intelligence>
  把苏格拉底、马基雅维利等历史思想家蒸馏成 AI 人格，组成多视角决策委员会，4.1k star。适合复杂问题让多个"人格"从不同角度分析后综合结论。

## 其他
- **airport-recommendations-2026** — 2026 年机场（代理节点）推荐
  <https://github.com/everett7623/airport-recommendations-2026>
  汇总 2026 年推荐的机场/代理服务，标注来源与特点。需要选代理服务时参考，注意甄别安全性与稳定性。

## 使用建议
- 前端生成后用 **taste-skill** 过审美、**hallmark** 去 AI 味
- 长流程任务用 **scientific-agent-skills** 托管
- token 敏感时用 **ponytail** 压缩
- 想复刻某领域专家 / 人格时，先从三个蒸馏仓库里找现成技能包
